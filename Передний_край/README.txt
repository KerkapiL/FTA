ПЕРЕДНИЙ КРАЙ - инструмент мастера

ЗАПУСК
  1. Двойной клик по start.bat
  2. Откроется браузер с приложением
  3. Окно консоли НЕ закрывать, пока играешь

ДАННЫЕ
  Всё хранится в браузере (IndexedDB).
  Раздел "Настройки" -> Экспорт/Импорт JSON.
  Раз в неделю делай экспорт и клади файл в data/backup/.

ВАЖНО
  Если чистишь кеш браузера - сначала сделай экспорт!
